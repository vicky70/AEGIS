# AEGIS
The AEGIS project is an ambitious system designed as an executive function co-pilot, using automated monitoring and accountability to help users maintain focus and complete tasks. Its deeply interconnected architecture features a central server that coordinates desktop activity tracking, network-level controls for enforcing internet restrictions, and a mobile client for location monitoring. At its core, LangGraph agents intelligently verify task completion by analyzing evidence such as activity logs and API checks from external services. A critical integrity monitor acts as a watchdog, using heartbeats and hash verification to ensure all components are running authentically, triggering a fail-safe lockdown if tampering is detected. The system prioritizes functionality and enforcement, with all evidence stored locally and communications secured over TLS. Implementation is broken into six phases, starting with a foundational server layer and progressively adding monitoring, intelligence, and anti-tampering capabilities. The ultimate goal is a system where integrity and accountability take precedence, ensuring users remain focused through enforced consequences rather than optional privacy features.
